Week 5 · Attention, an intervention, and the arrow task

Ready.
  1. Practice the arrow task (8 trials, with feedback).
  2. Baseline arrow task (60 trials, about 2 min).
  3. Intervention for 5 minutes: focused-attention meditation, physical exercise, Stroop training, or quiet rest.
  4. Arrow task again (60 trials), then results.
About 12 minutes. Needs no headset. Use the keyboard: arrow keys (or F / J).
